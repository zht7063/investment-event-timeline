# 股票区间研究 A → B → C 实施与验收

日期：2026-10-25（UTC+8）。本轮完成代码与本机验收；未更新公网服务器。阶段 D（订阅和报告历史比较）、E（正式权限/运维）不在本轮。

## 交付内容

- `/research`：股票代码和披露日期输入；真实名称解析，不依赖 `SYNC_CODES`。
- `/research/:id`：持久任务进度、来源覆盖、分页资料、自动事项及证据时间线、错误和恢复。
- `research-worker.ts`：独立持久任务 worker，短事务领取、租约/心跳、恢复、取消及令牌隔离；抓取与分析交替执行。
- 扶摇真实游标翻页；iFinD 逐日语义检索；北京时间二次过滤；日期未知不进入区间结论。
- 不可变资料快照、模型版本缓存；一篇资料提取多事项；对象/期次都有可验证原文时归并，不明确时独立保留。
- 支持/反驳/更正/替代关系绑定真实论断 ID、完整摘录、时间与单位口径；规则计算结论，事实性摘要使用原文引用。
- 区分自动提取与人工确认；未知模型时间保持未知，按来源精度显示四类时间，来源更新时间缺失明确为未知。
- 重试失败工作不额外扩大抓取预算；“继续检索更多资料”才增加未完成来源的检索额度。
- Compose 新增 `research` 服务；新表增量创建，无破坏性迁移。研究资料不受旧版演示重置影响。

## 明确边界与下一轮

- iFinD 实测会返回区间外结果，已本地过滤；逐日检索仍不保证所有新闻/公告穷尽。扶摇到预算时明确受限，无排序协议保证时不以首条旧日期提前结束。
- 仅片段/摘要；不声称全文核验，不自动访问任意外链。
- 自动归并依赖严格的原文对象和期次，有歧义时保持分开，因此可能有漏合并；不以同公司、同类型或相似标题强行合并。
- 单事项超过80条证据时关系分析明确标记受限；正文超过40000字保留资料但不截断生成结论。后续可增加分批关系核验和长正文处理。
- 研究结果目前独立于原有人工事件库，不自动写入“已人工确认”状态。可查看本次报告及其引用，但完整的跨报告版本比较、持续订阅、人工纠错审计留给 D。
- 队列单实例 SQLite，有活动任务数量保护，但尚非多用户权限/配额系统。生产模式、访客隔离等见 E。
- 未进行大规模负载、全部 A 股代码、所有交易所、全年历史或真实配额耗尽验收；未宣称完成这些覆盖。
