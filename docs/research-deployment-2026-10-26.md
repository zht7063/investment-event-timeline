## 发现并修复的问题

线上已有资料的研究页面刷新时报 React Server Component 序列化错误。Node 24.22.1 的 `node:sqlite` 返回无原型行对象，`researchStatus` 的资料和计数数组原先未经转换就传给客户端组件。

`src/server/research/store.ts` 现在将这两类行转换为普通对象。新增集成测试在旧开发运行时也模拟无原型行，先确认失败再修复；浏览器测试新增“资料已存在后刷新”的回归，并在最终 Docker 镜像的 Node 24.22.1 环境中运行完整回归。
