# 按股票与时间范围自动研究：实施方案

更新：2026-10-25（UTC+8）。依据：题目《投资事件情报与证据时间线》及用户确认的实际需求。

## 目标和范围

输入 A 股代码和披露日期范围，自动检索可用来源、识别多个事项、整理事实变化及证据冲突，逐步生成可追溯分析。人工确认用于纠错，不再作为阅读结果的前置条件。既有人工导入和事件审阅流程继续可用。

“全部相关信息”是遍历已授权来源在该区间提供的可检索结果，不承诺全网完整。每来源须公开覆盖状态、实际数量、错误、截断和仅片段限制。未检索到资料不代表没有事件；抓取完成与分析完成分别计数。

默认最近 30 天，可自定义日期。核心为公告与公司新闻；研报、政策、产业链信息仅在有真实来源和可解释关联时补充。行情只作背景。不得输出确定性涨跌预测、收益承诺和直接买卖建议。

## 用户流程与结果

1. 输入股票、起止日期，确认标的后创建后台任务。
2. 分来源展示检索进度，第一批资料到达即可阅读，分析随任务推进更新。
3. 结果包含区间概览、事件时间线、冲突与待核实事项、原文摘录和来源覆盖。
4. 刷新、离开页面不取消后台任务；可恢复查看、重试失败部分、取消任务。
5. 后续阶段支持持续跟踪和报告版本比较。

## 分析管线

标的解析 → 按来源/日期检索 → 分页与补抓 → 文档去重和版本识别 → 相关性判断 → 多事件/论断抽取 → 事件归并 → 支持/反驳/更正/替代关系 → 规则状态 → 引用式报告。

- 一篇资料可涉及多个事件。每条论断绑定具体事项和原文位置。
- 同公司或同类型不足以归并；结合对象、报告期、公告标识等。模型自由生成的事项键不能直接作为自动合并的可靠依据。
- 不明确的归并独立保留为待核实事项；不能阻塞其他分析。
- 转载保留出处链，不增加独立证据权重。
- 自动关联与人工确认分别记录。否认/更正必须指向具体论断，不能泛化为整个公司事件。
- 状态由规则计算，模型负责提取和结构化建议；摘要必须引用真实证据，校验失败回退结构化表达。

## 时间与覆盖

查询按披露日（北京时间）过滤，四类时间继续独立存储。缺失日期单列，不用抓取时间代替。历史区间研究不同于“系统当时已知”回看；后补资料不得倒灌系统历史。区间外前情和后续信息单列，不悄悄影响区间结论。

分页来源遍历游标；仅支持日期/数量上限的来源递归拆分日期窗口。单日仍满额、重复游标、未知排序、权限不足或预算耗尽均标记覆盖缺口。少于请求条数本身不能证明供应商检索穷尽。正文/摘要/片段分别标识，禁止暗示片段已完成全文核验。

## 架构和数据

沿用 Next.js、Node 24、SQLite、Docker。新增独立 worker，数据库任务队列支持租约、心跳、恢复与幂等；外部请求不得占用 SQLite 写事务。

新增 research_jobs（标的、区间、状态、租约），research_source_runs（窗口、游标、覆盖、错误），research_documents（任务和版本映射），研究事件/论断结果及 research_reports（证据清单、版本）。报告证据与本次查询绑定，不能直接显示全局事件当前结论而泄漏区间外资料。

接口：POST /api/research；GET /api/research/:id；GET /api/research/:id/report；取消与重试接口。首版轮询。共享版本可复用分析，重试不重复落库，取消一个任务不影响其他任务。

## 实施顺序和完成标准

### A：数据能力验证

实测多个股票和历史日期，核对工具 schema、分页/数量上限、全文、排序、日期过滤、错误和限流语义。保存脱敏报告与可复现探测脚本。实际未验证的能力标为未知，绝不编造参数。供应商不足时明确覆盖限制，不以模型弥补数据缺失。

### B：按需抓取闭环

实现股票日期表单、独立 worker、来源适配、补抓、断点恢复、去重、进度、资料列表、取消和重试。验收：新股票不改环境变量、不手动导入即可查询；中途重启可继续；接口失败可区分于零结果。

### C：自动事件分析

实现相关性、多事项抽取、稳健归并、冲突更正关系、自动规则状态、逐句引用和逐步结果。验收：不逐条人工确认即可得到真实资料分析；同公司不同事项不混合；模型失败不伪装成功。

### D：报告与持续跟踪（后续轮次）

完整报告历史比较、定时订阅和增量刷新、人工纠错审计；保留每次报告证据快照。

### E：生产验收（后续轮次）

生产模式关闭演示初始化和重置，强化权限、预算、备份及运维。A/B/C 本轮必须提供可运行部署配置和迁移，不将主链路运行依赖推迟到 E。

## 测试门槛

- 日期边界、多页、日内截断、重复游标、供应商错误、真实零结果和未知日期。
- 新股票自动查询，多事件拆分，同公司不同项目不误合并，转载不加权。
- 传闻→公告→更正/否认；冲突保留，数字单位与口径不混算。
- 摘录逐字校验、虚假引用拒绝、模型失败和重试。
- 后台重启恢复、并发领取和幂等、取消、重复提交及部分失败。
- 历史区间不混入后续证据，已生成结果可追溯。
- 浏览器成功/加载/错误/空结果、键盘和窄屏；类型检查、现有回归、生产构建。
- 真实接口实测与模拟测试分别记录，不能以 mock 通过证明真实接入。
