## 使用与后续工作

安装、更新、日志、备份恢复、域名接入及验收命令见 [Docker 安装说明](docker-install.md)。

域名确定并完成 DNS 解析后，把 HTTP Caddy 配置换为域名配置，验证 HTTPS 即可。当前保留演示版公开写入、共享资料、无模型额度控制的边界，不增加用户系统或复杂运维。片段证据语义保持原规则。

模型或数据源可能出现上游错误，资料会保留并显示失败状态，可从来源页重试；每来源每轮最多分析 10 条，剩余 pending 资料由后续轮次消化，已分析资料仍需人工确认归并。
